# FX Guard — 負けを小さく抑える全自動FX Bot

「勝つ」より「負けない」を優先した自動売買Botです。VPSで24時間動き、毎週自分のトレードを振り返ってルールを改善します。
普段の操作は不要で、スマホのブラウザで成績と「思考ログ」を見るだけです。

- **データ**：GMOコイン 外国為替FX の公開レート（**登録・口座開設・APIキー不要**）
- **売買**：実際の売値・買値を使って、Botの中で仮想的に約定（お金は動きません）
- **資金**：仮想資金1万円
- **目標**：月5%（0.25%リスクから始め、実績が出た分だけ段階的にリスクを上げる）

## 導入（初回だけ・約10分）

1. **GitHub** に `fx-guard` という空のリポジトリ（Public）を作り、このフォルダの中身を入れる
2. **VPS を契約**（Ubuntu 22.04 か 24.04、メモリ1GB以上。月1,000円前後）
3. VPS のコンソールに次の1行を貼り付けて Enter
   ```
   curl -fsSL https://raw.githubusercontent.com/takumiy888-eng/fx-guard/main/deploy/install.sh | sudo bash
   ```
4. 最後に表示される **管理画面のURL** と **パスワード** を控えて、スマホで開く

これで終わりです。Botが自動で過去約2.5年分のレートを取得して学習し（初回だけ30分ほど）、そのまま運用を始めます。
任意で、設定タブに Discord の Webhook URL を入れると、エントリー・決済・学習結果がスマホに届きます。

導入スクリプトが自動で行うこと：Python環境、自動起動と落ちた時の自動再起動、Botの見張り番（5分ごと）、無料のHTTPS証明書、ファイアウォール、OSのセキュリティ更新。

## 仮想売買のしくみ

- 新規注文：買いはその時の **買値（Ask）**、売りは **売値（Bid）** に、さらに0.2pips不利な価格で約定
- 損切り：価格が損切り値を越えたら、その時の価格で約定（窓開けなら損切り値より悪くなる）
- 利確：価格が利確値に届いたら利確値で約定
- 15秒ごとの最新レートに加えて、確定した1時間足の高値・安値でも判定するので、チェックの合間のヒゲやBot停止中の値動きでも損切りが漏れない（同じ足で損切りと利確の両方に届いたら損切り扱い）
- 週末やメンテナンスで市場が閉まっている間は約定しない

## 売買の考え方

**入る条件（すべて揃った時だけ）**
- 4時間足と1時間足のトレンドが同じ向き（ADXで強さも確認）
- 短期EMAまで押した（戻した）ところから、トレンド方向に反発した足

**入らない理由（ひとつでもあれば見送り）**
| 理由 | 内容 |
|---|---|
| 経済指標 | 重要指標の60分前〜30分後（カレンダーを3時間ごとに自動取得） |
| 週末・週明け | 金曜23時以降・土日・月曜10時まで |
| 時間帯 | 日本時間9時〜翌2時以外 |
| ボラ異常 | 値動きが平常の0.6倍未満 or 2倍超 |
| 通貨の偏り | 同じ通貨を同じ向きに2つ持たない（例：ドル円買い＋ユーロ円買い＝円売りが二重） |
| 学習した回避条件 | 週次学習で「はっきり負けている」と分かった条件 |

**早く逃げる決済**
- 損切りは必ず設定（ATR×1.5から学習で調整）
- **+1Rで半分利確し、残りは建値ストップ** → 勝ちかけた取引が負けに変わらない
- 残りは+2.5R前後で利確、48時間伸びなければ撤退、指標の30分前に撤退、週末前（土曜4時）に全決済

## 資金管理

| リスク段階 | 0.25% → 0.4% → 0.6% → 0.85% → 1.25% |
|---|---|
| 上げる条件（週1回・1段階ずつ） | 前回変更から15回以上・PF1.3以上・平均+0.15R以上・その段階でのDD3%以内・直近4週プラス・最新バックテストも基準内 |
| 下げる条件（即時） | 4連敗で1段階、週次ストップで1段階、最高値から-4%で最低段階 |

**何重ものストップ**：1日 -1%・1週 -2%・1か月 -4%（段階が上がると少し広がる）、3連敗でリスク半分、5連敗で24時間休止、最高値から-8%で完全停止（週次の再検証に合格した時だけ最低リスクで再開）。

## 自己学習（毎週土曜10時・市場休み中）

1. **ロールバック**：前回変更したパラメータで実運用が悪化していたら元に戻す
2. **回避条件の学習**：通貨ペア・時間帯・曜日・ボラ・トレンド強度ごとの成績から、90%の確からしさで負けている条件を「入らない条件」に追加（改善したら解除）
3. **パラメータ調整**：今の値の「隣」だけを試し、前半の期間で良く・後半（学習に使っていない期間）でも悪化しない場合だけ採用
4. **影のトレード**：見送ったシグナルを仮想で決済し、フィルターが本当に負けを避けているか確認
5. **1万円リプレイ**：最新ルールで1万円がどう増減するか（固定0.25% と 段階リスク）を再計算

変更はすべて理由つきで「思考ログ」に記録され、Discordにも届きます。

## 管理画面

- **ホーム**：仮想資金・今月の成績と月5%目標・リスク段階・保有・直近の重要指標
- **取引**：全取引の履歴
- **思考ログ**：Botが何を考えて、入った／見送った／変更したか
- **学習**：1万円バックテスト・条件別成績・回避条件・影のトレード・パラメータ履歴
- **設定**：通貨ペア・通知・パスワード・レート取得の確認・緊急操作（全決済・一時停止・仮想資金リセット）

## 注意

- GMOコインの1時間足は 2023年10月28日以降の分が公開されています。学習にはそこから直近までを使います
- バックテストの経済指標は、FOMC・米雇用統計の日程を再現したものと、運用開始後に蓄積した実データです。それ以外はボラ異常フィルターで補っています
- 過去の成績は将来の利益を保証しません。実際のお金で運用するかは、仮想運用で十分な期間（目安3か月以上）の実績を見てから判断してください
